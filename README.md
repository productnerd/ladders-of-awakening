# Ladders of Awakening

Forty-three staged maps of the path to awakening, side by side on one bottom-to-top scale. They come from East and West, and they are religious, mystical, philosophical and psychological. Each phase shows its tradition's own term and has a short description.

- `index.html`: the page (plain HTML, CSS and JavaScript, no build step).
- `data.js`: the maps. Each phase is `[title, description, from band, to band, own term, more on the term]`, and the bands run from 1 (ordinary life) to 9 (completion).

The site is published with GitHub Pages from `main` by `.github/workflows/pages.yml`.
